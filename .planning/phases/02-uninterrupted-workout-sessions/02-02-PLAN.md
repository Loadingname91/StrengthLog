<objective>
Add an optional "target weight" field to Routine Builder's per-exercise block editor, and use it in Active Workout as the weight-input placeholder/fill-in value on exercises that have no logged history yet — replacing a blank dash with a concrete, useful starting number for the user's very first time on a new exercise.

Purpose: today, the weight input's placeholder falls back to a bare "—" whenever `lastSessionSets` has nothing to show (i.e. the very first time an exercise is logged). A routine author who already knows roughly what weight a given exercise should start at has no way to communicate that to the person logging the workout. This plan closes BUILD-01 and BUILD-02.
Output: `src/screens/RoutineBuilder.jsx`, `src/state/reducer.js`, and `src/screens/ActiveWorkout.jsx` edited in place. No new files, no new reducer actions.
</objective>

## Phase Goal

**As a** routine author, **I want to** optionally set a target weight when building an exercise block, **so that** the first time I (or anyone importing my routine) logs that exercise, Active Workout suggests a sensible starting weight instead of showing nothing.

**This plan's slice of the story:** the target-weight field and its ghost-fallback behavior. (Session continuity — the floating bar and wall-clock hardening — is the unrelated concern covered by 02-01-PLAN.md; the two plans touch disjoint files and can run independently.)
